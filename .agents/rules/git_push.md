# Regola Git: commit e push su GitHub

Al termine di modifiche, refactoring o nuove feature richieste dall'utente:
1. Verificare che tutti i file modificati o creati siano integri e senza errori di sintassi.
2. Eseguire il commit dei file con un messaggio descrittivo.
3. Effettuare sempre il `git push origin main` su GitHub.
